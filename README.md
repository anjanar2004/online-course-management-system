# Online Course Management System

## Project Description

This is a Django-based Online Course Management System.

It allows users to view courses, enroll in courses, and manage courses based on their roles.

## User Roles

- Admin
- Staff
- User

## Main Features

- Signup
- Login
- Logout
- User Management
- Course Management
- Course Enrollment
- My Enrollments
- Reports Dashboard
- Role-based Access
- Django Admin

## Technologies Used

- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite

```bash
python manage.py runserver
